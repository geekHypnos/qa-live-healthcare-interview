### 阶段任务指令 数据库与登录实现

> 根据 DESIGN、PRD_LOGIN 和实施计划，先为公开医生字段、CSRF、登录失败、参数边界、会话恢复及退出编写失败测试；使用 JDBC、BCrypt 和 Spring Security 会话实现约定的五个接口，迁移原医生和患者 ID，不暴露密码。创建可重复导入的 SQL 和只绑定本机的 Compose。
